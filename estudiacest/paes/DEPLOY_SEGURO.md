# PAES - proteccion de deploy

Aplicar obligatoriamente `../DEPLOY_SEGURO_AREAS_ACADEMICAS.md`.

- Publicar solo con `npm run deploy:prod:safe` desde la raiz de `estudiacest`.
- Registrar cada guia interactiva y recurso esencial nuevo en `scripts/academic-release-manifest.json`.
- No publicar una guia parcial ni omitir admin, API, autoguardado o resultados.
- El artefacto debe conservar tambien NM3, NM4 y SIMCE.
